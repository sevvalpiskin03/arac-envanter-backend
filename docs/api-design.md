# API Taslağı

Tüm uç noktalar `/api/v1` altında sürümlenir.

## Planlanan kaynaklar

- `/auth`
- `/admins`
- `/companies`
- `/units`
- `/vehicles`
- `/vehicles/:vehicleId/mileage-records`
- `/service-records`
- `/maintenance-alerts`
- `/notifications`
- `/reports`

API hata yanıtları tutarlı bir kod, Türkçe kullanıcı mesajı ve gerektiğinde alan bazlı doğrulama ayrıntıları döndürür.
